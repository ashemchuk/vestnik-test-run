# OJS: итоговый отчёт по шаблону куратора

## 1. Версия и проект

OJS 3.5.0.5, образ `pkpofficial/ojs:3_5_0-5`. [Метка версии от 30.06.2026](https://github.com/pkp/ojs/releases/tag/3_5_0-5); [репозиторий PKP](https://github.com/pkp/ojs). Это дата коммита метки, а не отдельно установленная дата публикации GitHub Release.

## 2. Развёртывание

Docker Compose: OJS/Apache/PHP, MariaDB 11.8, Mailpit, постоянные тома. Colima ARM64, OJS AMD64 в эмуляции, 4 CPU / около 3.8 GiB RAM. Порты только localhost:8080 и 8025. Повторно использована установка от 07.10; длительность первой установки не измерена. Apache mutex исправлен конфигурацией fcntl; архитектура как причина не доказана. При финальном восстановлении устранены жёсткие ссылки между томами: архив создаётся с `tar --hard-dereference`. SQL и файлы восстановлены в отдельные новые тома; прежний контейнер тоже пересоздан. Реальная миграция между версиями не выполнена.

##  4. Плюсы и минусы

| Плюс                | Результат                                                                         |
| ------------------- | --------------------------------------------------------------------------------- |
| Полный цикл         | Подача, два раунда, отказ, PDF, корректура, публикация прошли без изменения ядра. |
| Публикация по одной | В добавлена в уже открытый выпуск, А сохранилась.                                 |
| Интеграции          | API-логгер, штатный импорт пользователей и OAI-PMH подтверждены.                  |
| Эксплуатация        | Docker, постоянные тома и восстановление SQL + файлов проверены.                  |

| Минус               | Результат                                                      |
| ------------------- | -------------------------------------------------------------- |
| Безопасность        | Утечка fullName/email через contributors API при double blind. |
| Локализация и сроки | Пропуски RU строк; даты в письмах на сутки раньше формы.       |
| Контактные авторы   | Один primaryContactId вместо двух контактов.                   |
| Форма рецензии      | Четыре своих варианта не заменяют обязательные шесть штатных.  |
