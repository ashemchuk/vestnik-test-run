# Архив действий полного прогона 12.10.2026

Это точные скрипты выполненных действий, сохранённые для аудита. Они не являются установщиком или безопасным повторяемым сценарием. **Не запускать на текущем журнале**: используются конкретные ID, создаются статьи, отправляются тестовые письма и выполняется удаление временных проб. Некоторые скрипты содержат неуспешные промежуточные попытки, позднее исправленные отдельным скриптом. Итог оценивается по evidence/full-run и отчёту, а не по предположениям первого вызова.

Оригинальные импорты ссылаются на /private/tmp/run-full.py и /private/tmp/ojs-client.py. Сохранённый переносимый клиент и помощники находятся уровнем выше: ojs-api-client.py и ojs-workflow-helpers.py. Для нового чистого стенда сначала адаптировать пути и ID, обеспечив резервную копию и отдельные тестовые аккаунты. prepare-full.py генерирует тестовые аккаунты; его повторный запуск изменит локальный файл учётных данных.

security-check.py содержит первую версию обработки ошибки удаления: ошибка DELETE ошибочно интерпретировалась как отказ загрузки. fix-security.py исправляет доказательства: PHP/HTML были приняты, удаление через REST запрещено. В отчёте использован исправленный security-results.json.

bc-submit.py задавал неверный первоначальный заголовок В о сортировке; fix-c-title.py привёл метаданные к фактическому тексту о двоичном поиске.
