# Короткий прогон OJS

Среда: локальная Colima ARM64, OJS 3.5.0-5 через эмуляцию AMD64,
MariaDB 11.8, SMTP Mailpit. Все пользователи, статьи и публикации тестовые.

## Выполнено

- Docker-стенд запущен; HTTP OJS и Mailpit проверен.
- Исправлена несовместимость Apache mutex с эмуляцией настройкой fcntl.
- Проверены соединения с базой и SMTP.
- Установка OJS завершена через штатный интерфейс; вход администратора проверен.
- Установлены русский и английский языки, часовой пояс Asia/Novosibirsk.
- Через штатный интерфейс создан «Тестовый журнал Вестник» / «Vestnik Test Journal»,
  путь `vestnik-test`, тестовая редакция `editor@example.test`.
- Русский основной; RU/EN включены для интерфейса, форм, подачи и метаданных.
- Страница журнала открывается; выпуски пока отсутствуют.
- Сохранено двойное слепое рецензирование, минимум 2 рецензии;
  доступ рецензента к файлам только после согласия. Ответ на приглашение —
  1 неделя, рецензия — 2 недели. Анонимность фактических файлов ещё не проверена.
- Штатным плагином UserImportExportPlugin созданы `editor` (Journal editor),
  `author` (Author), `reviewer1` и `reviewer2` (Reviewer).
  Назначения подтверждены в интерфейсе Users & Roles.
  Подготовка XML: `docker/prepare-test-users.php`, существующие роли экспортированы
  из журнала; прямые изменения базы и ядра не выполнялись.
- От имени `author` через интерфейс подана статья №1
  «Сравнение алгоритмов поиска дубликатов» / «Comparison of duplicate detection algorithms».
  Название, аннотация и ключевые слова заполнены на RU/EN.
  Загружены `test-data/article-a-v1.docx` и `test-data/article-a-v1.pdf` как Article Text.
  Рукопись содержит формулу и рисунок, без имени автора; DOCX визуально проверен после рендера.
  Один тестовый автор указан в метаданных; статус в его кабинете — Submission.
  Mailpit получил 4 письма: подтверждение автору, уведомления редактору и администратору,
  копию комментария редакции автору. Редактор статье пока не назначен.
- Назначен `editor` как Journal editor статьи №1. Администратор через штатный
  интерфейс перевёл статью в Review (Round 1) и назначил `reviewer1`, `reviewer2`.
  Обоим доступны выбранные DOCX/PDF после согласия; тип каждого назначения —
  Anonymous Reviewer/Anonymous Author. Оба пока в статусе Request Sent.
  Mailpit подтвердил уведомление редактору, переход на review автору и два приглашения.
  В проверенном письме reviewer2 имя автора отсутствует, ссылка ведёт на кабинет рецензента.
  Обнаружено расхождение дедлайнов: форма назначения показывала 14/21 октября 2026,
  отправленное письмо reviewer2 — 13/20 октября. Причина ещё не исследована
  (возможное преобразование даты/часового пояса).
- Оба рецензента приняли приглашения и отправили отзывы через собственные кабинеты
  (Login As администратора). В редакционном кабинете подтверждены оба Review Submitted:
  reviewer1 — Resubmit for Review, reviewer2 — Revisions Required.
  До согласия шаг Download & Review заблокирован и ссылки на файлы не показаны;
  после согласия reviewer1 успешно скачал PDF через интерфейс.
  Это проверка интерфейса; прямой запрет скачивания по URL до согласия ещё не проверен.
  В View All Submission Details первого рецензента имя автора не показано,
  но Keywords ошибочно отображается как Array — дефект отображения зафиксирован.
  Добавлены отдельные публичные замечания и служебные отметки R1/R2 в поле For editor;
  их недоступность автору предстоит проверить при отправке решения.
- Редакция прочитала и подтвердила оба отзыва кнопкой Confirm. До подтверждения
  OJS предупреждает о недостижении минимума подтверждённых рецензий.
  Записано решение Resubmit for Review (доработка с новым раундом).
  Автору отправлены публичные замечания обеих рецензий, рецензентам — отдельные
  уведомления о решении; доставка всех трёх писем подтверждена Mailpit.
  В штатной вставке allReviewerComments содержатся только публичные комментарии,
  имена заменены номерами; служебные отметки R1/R2 туда не попали.
  Проверены доставленное письмо и Notifications в кабинете автора: имена
  рецензентов и служебные комментарии отсутствуют.
  Статус автора: Revisions requested from the author to be taken to a new review round;
  доступна кнопка Upload revisions. Исправления ещё не загружены.
- Подготовлена обезличенная версия 2: подписаны оси графика, уточнена подпись,
  добавлены псевдокоды, примеры с повтором/без повтора, оценки ожидаемого времени
  и памяти. DOCX отрендерен в PDF, обе страницы визуально проверены.
  От автора загружены article-a-v2.docx/pdf (файлы 5/6), редактору отправлен
  ответ по пунктам в обсуждении «Ответ на замечания — версия 2».
  Статус автора автоматически изменился на Revisions submitted.
  Создан Review (Round 2): только DOCX/PDF версии 2 скопированы в файлы 7/8,
  ответ автора виден редакции. Рецензенты второго раунда пока не назначены.

## Завершение сокращённого прогона

По просьбе сократить работу из-за нехватки времени повторные отзывы,
отдельная корректура автором и добавление второй статьи пропущены.
Второй раунд создан, но не выполнен полностью; предупреждение OJS о минимуме
подтверждённых рецензий при принятии явно подтверждено в интерфейсе.

- Статья №1 принята и переведена через Copyediting в Production.
- Проверенный PDF версии 2 загружен отдельной публичной гранкой PDF (Russian), файл 9.
- Создан и опубликован выпуск Vol. 1 No. 1 (2026): Тестовый выпуск, issueId=1.
  Статья включена в выпуск и опубликована 2026-10-07.
- Публичная страница: http://localhost:8080/vestnik-test/en/article/view/1
- Запросы без авторизации (только cookie языка, без OJSSID) подтвердили:
  страница статьи HTTP 200; публичный PDF HTTP 200, application/pdf, сигнатура %PDF,
  54863 байта. Приватные файлы 1 и 7 возвращают JSON status=false:
  The current role does not have access to this operation. Файлы не выданы.
  OJS использует HTTP 200 для этого JSON-отказа — следует проверять и тело ответа.

## Оставшиеся проверки полного сценария

- Назначить рецензентов во втором раунде, получить повторные отзывы,
  принять статью и пройти корректуру.
- Исследовать расхождение дат дедлайнов между формой и письмом.
- Публикация первой статьи и добавление второй в тот же опубликованный выпуск.
- Анонимность и запрет скачивания приватной рукописи посторонним.
- API и точки расширения для целевых автоматизаций.
