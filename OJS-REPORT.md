# Отчёт о локальном прогоне OJS

## Развёртывание

Развёрнут OJS **3.5.0-5** через Docker Compose на macOS с Colima ARM64. Использован образ `pkpofficial/ojs:3_5_0-5` для AMD64 с эмуляцией. Вместе с OJS запущены MariaDB 11.8 и Mailpit для перехвата тестовых писем.

- OJS: `http://localhost:8080`.
- Mailpit: `http://localhost:8025`.
- База, файлы приложения, рукописи и письма сохраняются в томах Docker.
- Установка выполнена через веб-интерфейс. Ядро OJS не изменялось.

При запуске Apache возникла ошибка `Couldn't create the mpm-accept mutex`. Добавление `Mutex fcntl:/var/lock/apache2 default` устранило её.

## Выполненный сценарий

| Этап              | Результат                                                                                                                          |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Настройка журнала | Создан «Тестовый журнал Вестник», включены RU/EN для интерфейса и метаданных                                                       |
| Пользователи      | Созданы администратор, редактор, автор и два рецензента                                                                            |
| Подача            | Автор подал статью «Сравнение алгоритмов поиска дубликатов»: DOCX и PDF, название, аннотация и ключевые слова на RU/EN             |
| Рецензирование    | Настроено двойное слепое рецензирование с минимумом двух отзывов; назначены два рецензента                                         |
| Отзывы            | Оба приняли приглашение и отправили отзывы: `Resubmit for Review` и `Revisions Required`                                           |
| Решение           | Редакция подтвердила отзывы и отправила автору замечания для доработки                                                             |
| Доработка         | Автор загрузил DOCX/PDF версии 2 и ответ на замечания; создан второй раунд                                                         |
| Принятие          | Статья принята с подтверждением предупреждения OJS о минимуме рецензий во втором раунде, переведена через Copyediting в Production |
| Публикация        | Внешний PDF версии 2 загружен как гранка; опубликован тестовый выпуск Vol. 1 No. 1 (2026) со статьёй                               |

Публичная статья: [открыть на локальном стенде](http://localhost:8080/vestnik-test/en/article/view/1).(бугага)

## Подтверждённые проверки

- Кабинеты автора, редактора и рецензента использованы; автор видел статусы подачи и доработки.
- До согласия рецензента ссылки на рукопись не показывались; после согласия PDF скачивался.
- Имя автора не отображалось в проверенном интерфейсе рецензента и письме-приглашении. Тестовая рукопись подготовлена обезличенной.
- Письмо с решением и уведомление автору содержали публичные замечания без имён рецензентов и служебных комментариев.
- Письма о подаче, приглашениях и решении получены в Mailpit.
- Без авторизации открывались страница статьи и публичный PDF. Запросы двух приватных файлов отклонялись с `status=false`, содержимое файлов не выдавалось.

## Обнаруженные проблемы

| Проблема                                                      | Результат                                    |
| ------------------------------------------------------------- | -------------------------------------------- |
| Ошибка блокировки Apache при запуске                          | Устранена настройкой `Mutex fcntl`           |
| Даты дедлайнов в форме и письме различались на день           | 4/21 октября в форме, 13/20 октября в письме |
| Ключевые слова в кабинете рецензента отображались как `Array` | Дефект отображения                           |

## Почему брать OJS за основу

| За                                              | Против                                                         |
| ----------------------------------------------- | -------------------------------------------------------------- |
| Готовый цикл от подачи до публикации            | Соблюдение регламента зависит от редактора                     |
| Кабинеты, письма и права доступа                | Обнаружены дефекты дат и ключевых слов                         |
| Русский и английский языки(в целом почти любые) | На нашем ARM64-стенде понадобились эмуляция и настройка Apache |
| Прогон без изменения ядра                       | PHP: ))))                                                      |
